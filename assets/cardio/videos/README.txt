Optional offline movement clips

No generated videos are bundled yet. The player uses local, translated movement instructions and a timer when a clip is absent.

Place reviewed MP4/H.264 clips here, named after RoutineStep.exercise (for example ankleRocks.mp4). The directory is registered in pubspec.yaml. No streaming or runtime downloads are performed. Use the same clip in every locale; silent demonstrations are preferred, spoken audio must be English.

Generation prompts are in the ignored .tmp/cardio-video-prompts/ directory in the developer workspace. For each clip, retain model/provider, generation date, applicable account terms, commercial-use review and movement-quality approval. Generated content is not automatically public domain or medically correct. Do not publish before human review.
